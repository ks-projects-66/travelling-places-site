# Travelling Places imagery delivery

This folder contains the ten requested production-ready photographs and their licence provenance.

## Contents

- `photos/`: clean JPEG originals for the website build
- `imagery-manifest.json`: machine-readable source, licence, release, cost, dimensions, and hash data
- `LICENSING.md`: human-readable licence register
- `QA.md`: delivery and crop verification
- `process_images.py`: reproducible sRGB conversion, crop, and export settings
