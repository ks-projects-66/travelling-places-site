Rules agents can apply automatically

The package includes machine-readable tokens, direct instructions for Codex and Claude Code, and a brand checker that identifies prohibited styling and punctuation before interface work is accepted.

Always

  • Use approved tokens and self-hosted fonts.
  • Keep white as the predominant surface.
  • Use one primary action per section.
  • Keep interactive targets at least 44px.
  • Respect keyboard access and reduced motion.

Never

  • Use eyebrow headings or decorative section numbering.
  • Use italic type or oversized display text.
  • Use long dash punctuation or diagonal arrow icons.
  • Place blue text on navy or red text on navy.
  • Use underlined calls to action or default library themes.
